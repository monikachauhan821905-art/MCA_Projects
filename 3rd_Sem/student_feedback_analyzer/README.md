# Student Feedback & Course Review Analyzer
**SDG 4 - Quality Education** | Minor Project (NLP + Deep Learning)

Turns raw student course reviews into actionable insight for faculty:
1. **Sentiment** (negative / neutral / positive) with TF-IDF + Logistic Regression selected for live predictions based on held-out validation; compared against LSTM, Bi-LSTM, GRU, and TF-IDF+NB
2. **Keywords** that drive praise and complaints (TF-IDF)
3. **Aspect report** - which area (teaching, exams, labs, pace...) needs fixing first
4. **Next-word suggestion** while typing feedback (GRU)
5. **Streamlit dashboard** with sentiment and model-performance overview, plus interactive review analysis

## Run it
```bash
pip install -r requirements.txt
python src/generate_dataset.py      # creates the synthetic demo data/reviews.csv if needed
python src/prepare_public_reviews.py  # downloads and labels public rating-based reviews
python src/train_sentiment.py --data data/reviews_public.csv  # EDA + 5-model comparison + plots
python src/train_nextword.py        # GRU next-word model
streamlit run app.py
```

`prepare_public_reviews.py` writes a separate, balanced `data/reviews_public.csv`;
it does not overwrite the synthetic demo dataset. The source is the
[RateMyProfessors reviews dataset](https://huggingface.co/datasets/Z-H-Che/ratemyprofessors_reviews),
which reports scraped RateMyProfessors reviews and original 1–5 ratings. Labels
are rating-derived proxies (1–2 negative, 3 neutral, 4–5 positive), not
independent human sentiment annotations; non-integer ratings are excluded.
The dataset card declares Apache-2.0 and describes the collection method.
This dataset has professor/course reviews, so review polarity can sometimes
differ from the numeric rating. On the prepared 9,000-review sample, TF-IDF +
Logistic Regression reached 72.4% accuracy on an 1,800-review held-out split.
Evaluate predictions on a held-out set before using the model beyond a
classroom demo.

### Windows with a long project path
TensorFlow includes deeply nested files that can exceed Windows' path-length limit when installed inside a long OneDrive project path. Create the environment in a short path and run the app with its Python:
```powershell
if (!(Test-Path C:\tfv\Scripts\python.exe)) { python -m venv --system-site-packages C:\tfv }
C:\tfv\Scripts\python.exe -m pip install -r requirements.txt
C:\tfv\Scripts\python.exe -m streamlit run app.py
```
Run these commands from the project folder.

## Using REAL data (recommended before final submission)
`data/reviews.csv` is **synthetic** (generated by `generate_dataset.py`). Replace it with any CSV that has
columns `text` and `sentiment` (negative/neutral/positive), e.g. a Kaggle course-review or Coursera-reviews
dataset (map star ratings: 1-2 -> negative, 3 -> neutral, 4-5 -> positive). Then re-run the three commands above.
Expect lower accuracy and larger gaps between models on real data - that is normal and makes a better report.

## Project structure
```
app.py                  Streamlit web app (4 tabs)
src/preprocess.py       cleaning, tokenizing, stop words, stem, lemma
src/generate_dataset.py synthetic dataset generator
src/train_sentiment.py  EDA + TF-IDF / LSTM / Bi-LSTM / GRU comparison
src/train_nextword.py   GRU next-word model
src/keywords.py         TF-IDF keywords + aspect-wise report
models/  reports/  data/
```

## Suggested 2-person split
